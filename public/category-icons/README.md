# Иконки категорий редактора

Поместите ваши собственные иконки в эту папку `/public/category-icons/` с соответствующими названиями файлов (в формате `.svg` или `.png`).

### Список категорий и имена файлов:

- `favorites.svg` (или `.png`) — Избранное
- `warehouse.svg` — Склад
- `arches.svg` — Арки
- `stands.svg` — Стойки
- `tables.svg` — Столы
- `screens.svg` — Ширмы
- `flowers.svg` — Цветы
- `compositions.svg` — Композиции
- `vases.svg` — Вазы
- `details.svg` — Детали
- `textiles.svg` — Текстиль
- `light.svg` — Свет
- `podiums.svg` — Подиумы
- `furniture.svg` — Мебель
- `balloons.svg` — Шары
- `themes.svg` — Тематика

Если файл с вашей иконкой присутствует в папке `/public/category-icons/`, он автоматически появится в боковой панели категорий редактора!
