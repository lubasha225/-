# Каталог элементов декора для категорий (Category Assets)

В этой папке хранятся встроенные и пользовательские SVG/PNG элементы для категорий декора редактора:
- `/public/category-assets/` — загружаемые готовые объекты для каждой из категорий (Арки, Мебель, Свет, Текстиль, Флористика и др.).
- Доступ из кода: `/category-assets/название_файла.png` или `data:image/...`
